# GitHub Guide: Setup and Basics

## What is GitHub?

GitHub is a cloud-based platform where you can store, share, and collaborate on code. It uses **Git**, a version control system that tracks changes in your files.

Think of it as a social network for developers. You can:
- **Host your code**: Keep your projects safe in the cloud.
- **Collaborate**: Work with others on the same project without overriding each other's work.
- **Showcase**: Use your profile as a portfolio to show off your skills.

## Step 1: Create a GitHub Account

1.  Go to [github.com](https://github.com).
2.  Click **Sign up**.
3.  Enter your email address, create a password, and choose a username.
    *   *Tip: Choose a professional username (e.g., `jdoe`, `jane-doe-dev`).*
4.  Solve the puzzle to verify you are human.
5.  Verify your email address using the code sent to your email.

## Step 2: Set Up Your Profile

Once logged in, you can customize your profile to make it stand out.

1.  **Profile Picture**: Upload a clear photo or an avatar.
2.  **Bio**: Add a short description of yourself.
    *   *Example: "Software Engineer enthusiast learning Python and AI."*
3.  **Location & Company**: Fill these in if you want people to know where you are based.
4.  **Social Links**: Add links to your website, Twitter/X, or LinkedIn.

### The Profile README
You can create a special repository that acts as a comprehensive "About Me" section on your profile.

1.  Create a new repository with the **same name as your username**.
2.  Check the box **"Initialize this repository with a README"**.
3.  Edit the `README.md` file in that repository. Anything you write there will appear at the top of your GitHub profile page!

## Basic Concepts

- **Repository (Repo)**: A folder for your project. It contains all project files and the revision history.
- **Commit**: A snapshot of your changes. Think of it as a "save point".
- **Branch**: A parallel version of your repository. Use branches to work on features without affecting the main code.
- **Push**: Sending your local commits to GitHub.
- **Pull**: Fetching changes from GitHub to your local machine.
- **Pull Request (PR)**: Proposing changes to a repository. This is how you submit code to open source projects or collaborate with teammates.

## Next Steps

Now that you have an account, try creating your first repository!
1. Click the **+** icon in the top right corner.
2. Select **New repository**.
3. Give it a name (e.g., `hello-world`).
4. Click **Create repository**.
